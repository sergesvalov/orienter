# ⚙️ API Gateway (Node.js)

Промежуточный бэкенд-сервис (BFF - Backend for Frontend), проксирующий запросы между клиентами (Web, Android) и базой данных Supabase.

## Зачем он нужен?
1. **Безопасность**: Защищает базу данных от прямого доступа с клиентских устройств и от спама регистрациями (DDoS).
2. **Логирование**: Собирает логи всех HTTP-обращений клиентов в одном месте.
3. **Валидация**: Жестко проверяет входящие данные перед отправкой в БД с помощью Zod.

## Стек технологий
- **Фреймворк**: Express + TypeScript
- **Валидация**: Zod
- **Безопасность**: Helmet + Express Rate Limit
- **Логирование**: Morgan
- **Тестирование**: Jest + Supertest (Автоматизированный QA Pipeline)

## Структура
- `routes/` — Маршруты API (`/events`, `/registrations`).
- `tests/` — Интеграционные тесты (E2E).
- `index.ts` — Точка входа, настройка Middleware и Graceful Shutdown (по сигналам SIGTERM/SIGINT).

## Запуск и Тесты
Для локальной разработки используйте Docker Compose в корне проекта.

Запуск авто-тестов (используется Jenkins CI/CD):
```bash
npm install
npm test
```
